## 添加新法律的步骤

### 1. 将法律文件放入 `data/laws` 目录

将你的法律文件（**.docx 格式**）放到 `data/laws/` 文件夹中。

文件命名建议遵循现有格式：
```
{法律全名}_{日期}.docx
```
例如：`中华人民共和国个人信息保护法_20210820.docx`

### 2. 重新生成数据文件

在终端执行以下命令即可：

```powershell
python generate_laws_data.py
```

这会自动完成：
- 扫描 `data/laws/` 下所有 `.docx` 文件
- 提取法律名称、颁布日期、分类、所有法条内容
- 生成新的 `frontend/static/js/laws_data.js`，知识库即时生效

**无需修改任何代码**，分类标签会根据法律名称自动匹配。
